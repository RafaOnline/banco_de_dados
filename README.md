# 🗄️ Guia Completo de Comandos SQL

Bem-vindo ao **Guia Completo de Comandos SQL** — um repositório criado para servir como **referência prática e rápida** sobre os principais comandos SQL usados no dia a dia, desde operações básicas até recursos avançados como *joins*, *views*, *transações* e *funções de agregação*.

---

## 📚 Sobre o Projeto

Este repositório foi criado com o objetivo de **documentar os comandos SQL** mais utilizados em bancos de dados relacionais (como PostgreSQL, MySQL e SQL Server).

É ideal para:
- Estudantes de **Análise e Desenvolvimento de Sistemas** 🧑‍💻  
- Pessoas se preparando para **entrevistas técnicas** 🎯  
- Desenvolvedores que querem **refrescar a memória** sobre comandos SQL 💾  
- Profissionais que desejam ter uma **documentação de referência rápida** 📘  

---

## 📖 Conteúdo do Guia

O arquivo [`comandos_sql.md`](./comandos_sql.md) contém todos os tópicos a seguir, com exemplos práticos e explicações claras:

### 🧱 Estrutura e Constraints
- `CREATE TABLE`, `ALTER TABLE`, `DROP TABLE`
- `PRIMARY KEY`, `FOREIGN KEY`, `UNIQUE`, `NOT NULL`, `CHECK`
- Renomear e remover colunas

### 💾 Operações CRUD
- `INSERT`, `SELECT`, `UPDATE`, `DELETE`
- Inserção condicional (`ON CONFLICT`)
- Atualizações múltiplas e retorno de dados (`RETURNING`)

### 🔗 Chaves Estrangeiras
- Criação, referência e remoção de FKs
- Uso de `ON UPDATE` e `ON DELETE`

### 🕒 Funções de Data e Hora
- `CURRENT_DATE`, `AGE()`, `EXTRACT()`
- Cálculo de idade e faixa etária

### 🧠 Consultas e Filtros
- `WHERE`, `IN`, `BETWEEN`, `LIKE`, `NOT LIKE`
- `ORDER BY`, `DISTINCT`, `GROUP BY`, `HAVING`
- Subconsultas e expressões condicionais (`CASE WHEN`)

### 🔄 Junções e Combinações
- `INNER JOIN`, `LEFT JOIN`, `RIGHT JOIN`, `FULL JOIN`
- `UNION`, `UNION ALL`, `INTERSECT`

### 📊 Funções de Agregação
- `COUNT`, `SUM`, `AVG`, `MIN`, `MAX`, `VARIANCE`, `STDDEV`

### 👁️ Views e Relatórios
- `CREATE VIEW` para consultas personalizadas
- Relatórios com `ROLLUP` e `CUBE` (PostgreSQL)

### 🧩 Transações
- `BEGIN`, `COMMIT`, `ROLLBACK`, `SAVEPOINT`
- Controle de transações em operações críticas

### 🧮 Funções de Texto e Matemáticas
- `UPPER()`, `LOWER()`, `SUBSTRING()`, `LENGTH()`
- `ABS()`, `CEIL()`, `FLOOR()`, `ROUND()`
